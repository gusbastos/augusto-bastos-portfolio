# Augusto Bastos Portfolio

Static live-resume and portfolio website. No build step is required.

## Preview

Open `index.html` in a browser.

The detailed professional profile is available at `profile.html`.

Neutral organisation logo fallbacks live in `assets/logos/` and can be replaced with approved official assets using the same filenames.

## Deploy

Deploy the contents of this folder to GitHub Pages, Vercel, Netlify, or any static host.

## Required asset

Place Augusto's real CV at `Augusto-Bastos-CV.pdf` in this folder. The homepage and project pages already link to that filename.
