# Organisation logos

The portfolio supports SVG, PNG, WebP, JPEG and GIF logo assets. The file extension must match the image's actual format; renaming a PNG or WebP file to `.svg` will prevent browsers from displaying it correctly.

Current profile references:

- `boq-group.webp`
- `bank-of-queensland.png`
- `me-bank.png`
- `virgin-money-australia.webp`
- `torrens-university.png`
- `banco-do-brasil.webp`

For a drop-in replacement, export the new image in the same format and keep the exact filename. If its format or filename changes, update the matching `src` in `profile.html`. The page already supplies accessible `alt` text and responsive dimensions.
